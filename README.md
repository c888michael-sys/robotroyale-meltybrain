# robotroyale-meltybrain

Project research, decisions, design, and build records for the Robot Royale meltybrain.

## Repository structure

```text
research/
  code/                  # Firmware, control methods, and project surveys
  parts/                 # Component research
  chassis/               # Chassis research

decision/
  code/                  # Software decisions
  parts/                 # Component decisions
  chassis/               # Chassis decisions

design/
  chassis/               # Mechanical designs
  wiring-schematics/     # Wiring diagrams and electrical schematics

building/
  chassis/               # Chassis construction
  wiring-debugging/      # Wiring work and troubleshooting
  testing-calibration/   # Test results and calibration records
```
